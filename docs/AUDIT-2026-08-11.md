## Kiểm soát đã có

- `AdminIngestionController` yêu cầu role `Admin`, có rate-limit riêng. Job và
  artifact thuộc user tạo job khi xem lịch sử.
- R2 private với presigned PUT/GET URL; access key không đi qua frontend.
- Worker endpoint chỉ chấp nhận worker key tối thiểu 32 ký tự và so sánh
  constant-time. Queue claim dùng PostgreSQL transaction và `SKIP LOCKED`.
- Video được tách **audio-only**, validate extension/header, có FFmpeg timeout,
  giới hạn kích thước và poll Gemini Files state; audio tạm/Gemini file được
  cleanup trong `finally`.
- Nội dung crawler/audio được coi là untrusted; prompt yêu cầu chỉ trích xuất
  nghiệp vụ. Scenario được schema-validate và dừng ở `AwaitingReview`, không
  auto-publish.
- Backend log exception gốc trong global exception handler; client nhận lỗi
  khái quát thay vì stack trace.

## Finding cần ưu tiên

| ID | Mức | Bằng chứng | Ảnh hưởng | Khuyến nghị |
| --- | --- | --- | --- | --- |
| A-01 | High | Lease ingestion là 15 phút, nhưng workflow cho phép 30 phút; FFmpeg, Gemini Files và model generation không có cơ chế renew lease | Job dài có thể bị `complete` trả 409 sau khi đã tốn chi phí; run sau mới recover/retry | Thêm endpoint heartbeat/renew lease hoặc giới hạn workflow/media dưới lease; test trường hợp completion sau lease |
| A-02 | High | `SchemaBootstrapper` vẫn chạy DDL/UPDATE/index creation khi mọi API instance khởi động; chỉ migration ingestion là versioned | Drift, lock hoặc deploy race khi scale/redeploy Render | Chuyển toàn bộ schema bootstrap sang versioned migrations chạy một lần trong pipeline deploy |
| A-03 | Medium | Upload complete chấp nhận `actualBytes <= ExpectedBytes`; không từ chối artifact đã quá `ExpiresAt` | Upload partial/cũ có thể vào queue, lỗi muộn tại FFmpeg/Gemini | Bắt buộc bằng kích thước dự kiến, kiểm tra expiry/content metadata và thêm test partial upload |
| A-04 | Medium | Cleanup artifact và recover lease chỉ chạy khi worker gọi `claim` | Lịch GitHub Actions hằng ngày giảm rủi ro, nhưng schedule bị trễ/tắt sẽ để object/job quá hạn lâu hơn | Tạo cleanup scheduled riêng hoặc R2 lifecycle rule; metric số artifact/job quá hạn |
| A-05 | Medium | Không có CI workflow chạy .NET unit, Python tests và Playwright; `requirements.txt` còn dải phiên bản `>=` | Regression hoặc dependency drift chỉ lộ lúc deploy/run worker | Thêm GitHub CI và lock Python dependency (ví dụ `pip-tools`/uv lock); giữ ingestion workflow chỉ cho tác vụ thật |
| A-06 | Medium | Rate limit phân vùng theo `RemoteIpAddress`, nhưng app chưa cấu hình forwarded headers/trusted proxy | Sau Render proxy có thể rate-limit cả người dùng chung IP hoặc không phản ánh IP thật | Cấu hình `ForwardedHeadersOptions` cho proxy đáng tin cậy và kiểm thử 429 sau proxy |
| A-07 | Medium | UI chỉ hiện `ErrorCode`; worker map nhiều exception thành `processing_failed`, không có tracing/alert | Khó phân biệt R2, FFmpeg, Gemini quota hay JSON validation trong vận hành | Ghi structured log có `jobId`, stage, duration, provider; thêm alert/health dashboard tối thiểu |
| A-08 | Low | JWT được giữ trong `localStorage` | XSS tương lai có thể đánh cắp bearer token | Giữ escaping/CSP chặt; dài hạn cân nhắc HttpOnly secure cookie + CSRF strategy |
| A-09 | Low | Kiểm tra media hiện dựa extension, content type và 16-byte magic header trước FFmpeg | Chưa có antivirus, `ffprobe` duration/stream limits hoặc quota chi tiết | Thêm malware scan/quarantine, `ffprobe`, giới hạn thời lượng và quota theo Admin trước khi mở rộng |

## Regression tests cần bổ sung

- Claim job, giả lập xử lý vượt lease và xác minh renewal/recovery không nhân
  đôi scenario.
- Upload một object nhỏ hơn metadata; complete phải từ chối. Kiểm thử artifact
  expired và cleanup/lifecycle.
- Worker success/failure cho FFmpeg timeout, Gemini `FAILED`, Gemini poll
  timeout, JSON invalid và cleanup file.
- CI: backend unit; Python full unittest trong Python 3.12; frontend build,
  contract, Playwright upload mock và axe; integration suite dùng Postgres test.

test trong database/R2 test tách biệt và review trước khi deploy.
